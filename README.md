# micseed

Hold to speak (or hum). Hash the sound. Get a Solana-ish address out.

Microphone → short PCM / spectrum slice → SHA-256 → PDA-style address preview.
The input is hearing — not another fee/slot costume. Sibling to drawseed (ink) and camseed (light). Distinct from hearslot (chain → sound).

**Target live:** https://robertkodes.github.io/micseed/
